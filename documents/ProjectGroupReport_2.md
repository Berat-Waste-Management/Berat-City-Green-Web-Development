## 3. Evaluation of benefits and drawbacks

The most useful aspects of using AI is that it can provide a useful tool for debugging; if there is an issue that is difficult to understand why it might be throwing that error AI can help debug that error quickly. Using it to generate codee just results in incorrect code with errors that will pop up in the future, and is not useful in the long run. 

The limitations with AI as well is that it doesn't understand the implementation you want accurately so if you just ask it to generate a portion of code it won't create it the way you want it to, so you have to go and edit the code to what you want it to look like anyway. 

When generating our tests as well, they were mostly created by us because the AI didn't understand properly what we wanted to test and in order for it to understand we would need to esentially provide it with all of our code which is more work than it is worth. 

As mentioned above, at times, generative AI would attempt to change more than it needed to in order to meet its own standards and quality of code. This would resort in the occasional tedious process of providing more detailed and oddly worded/specific generative AI prompts to ensure it wouldn't delete or alter necessary, working code that it deemed roundabout. 


## 4. Your overall perspective

The use of AI tools enhanced our learning mainly because we used AI for debugging, and not for generating code so it didn't create anything that would cause issues but it was used instead to solve issues that came up as we were working through the implementation.
